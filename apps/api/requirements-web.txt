# Slim dependency set for serving the read-only API (no pipeline workers).

# The full pyproject dependency list pulls sentence-transformers, which pulls
# torch — roughly 2.5 GB installed. That will not build or run on a small
# Render instance, and none of it is needed to serve the site: importing
# app.main loads no torch, sentence_transformers, spacy, sklearn or hdbscan,
# because every pipeline service imports them lazily inside function bodies.
#

#   sentence-transformers, scikit-learn, hdbscan, spacy  -> clustering and
#       embedding generation (pipeline only)

#       googlenewsdecoder                                -> crawling (pipeline only)
#   agno                                                 -> LLM agents (pipeline only)
#   boto3                                                -> S3/R2 uploads (avatars)
#
# Keep this in sync with apps/api/pyproject.toml when you add a runtime
# dependency that the API serves requests with.
